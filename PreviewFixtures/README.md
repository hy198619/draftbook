# Preview fixtures

`drafts.json` contains the three visual test drafts written by the user in an isolated DraftBook preview on 2026-10-21.

Run `scripts/launch-preview.sh` to build the current app and launch it with a fresh temporary copy of this data. Changes made inside a launched preview do not modify the fixture or the user's production DraftBook data.

Keep the draft contents, colors, ordering, leading blank lines, and Markdown syntax intact unless the visual test cases are intentionally updated.
