# DraftBook（草稿本）0.9.3 Public Beta

DraftBook 是给一人公司主理人和内容创作者的草稿本，一个文字的临时中转站。

## 直接下载

[下载 DraftBook 0.9.3（macOS 通用版）](https://github.com/hy198619/draftbook/releases/download/v0.9.3/DraftBook-v0.9.3-macOS-unsigned.dmg)

系统要求：macOS 14 Sonoma 或更高版本，支持 Apple Silicon 与 Intel Mac。

## 这次更新了什么

- 修复搜狗拼音等中文输入法在候选、组词时偶发“吞字”的问题；
- 默认“未分类”标签的色样与实际标签统一为黑色；
- 移除到期草稿标签的橙色描边；
- 0.9.2 的其余功能保持不变。

## 主要功能

- 打开即写，自动保存；
- `⌘↩︎` 划定草稿，新内容保持在最上方；
- 彩色标签、固定、复制和 Markdown；
- 全文搜索及标签筛选；
- 清理台、延期、存档和回收站；
- TXT、Markdown、完整 JSON 导出；
- 每日自动备份和完整备份恢复。

## 安装前请注意

这个测试版本尚未使用 Apple Developer ID 签名，也没有经过 Apple 公证。macOS 第一次打开时会阻止运行。请先双击尝试打开，再进入 `系统设置 → 隐私与安全性`，点击“仍要打开”。

完整步骤见仓库中的[安装说明](https://github.com/hy198619/draftbook/blob/main/docs/INSTALL.md)。请只从本仓库 Releases 下载。

草稿完全保存在本机，当前没有账号、分析统计或网络上传。数据尚未加密，请勿把它当作密码管理器。
