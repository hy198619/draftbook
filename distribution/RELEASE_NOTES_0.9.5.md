# DraftBook（草稿本）0.9.5 Public Beta

给一人公司主理人和内容创作者的草稿本，一个文字的临时中转站。

[下载 DraftBook 0.9.5（macOS 通用版）](https://github.com/hy198619/draftbook/releases/download/v0.9.5/DraftBook-v0.9.5-macOS-unsigned.dmg)

系统要求：macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

## 本次更新

- 新增“草稿本 → 检查更新…”。只在主动点击时查询 GitHub；发现新版后可下载、校验 SHA-256 并打开 DMG。安装仍需退出旧版并手动替换应用。已安装的 0.9.4 尚无此功能，需要手动安装一次 0.9.5。
- 修复 `*文字*` 在 Markdown 预览中没有呈现斜体的问题。
- 更新软件内“帮助 → 草稿本使用说明”，按实际场景介绍记录、编辑、分类、清理与数据安全。

## 安装说明

当前仍是未经过 Apple Developer ID 签名和公证的公开测试版。首次打开步骤见[安装说明](https://github.com/hy198619/draftbook/blob/main/docs/INSTALL.md)。

Release 同时提供 `SHA256SUMS.txt`。所有草稿保存在本机；手动检查和下载更新时会连接 GitHub，不会上传草稿内容。
