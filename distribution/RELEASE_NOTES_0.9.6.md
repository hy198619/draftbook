# DraftBook（草稿本）0.9.6 Public Beta

给一人公司主理人和内容创作者的草稿本，一个文字的临时中转站。

[下载 DraftBook 0.9.6（macOS 通用版）](https://github.com/hy198619/draftbook/releases/download/v0.9.6/DraftBook-v0.9.6-macOS-unsigned.dmg)

系统要求：macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

## 本次更新

- 顶部改用“草稿区⌄”切换草稿区、清理台、存档区和回收站，去掉容易让人误以为可修改文件名的铅笔图标；“待处理”仍是独立的整理入口。
- 五种彩色标签默认命名为“分类1”至“分类5”，可在“设置 → 标签”自定义名称；黑色标签固定为“未分类”。搜索、草稿区和存档区共用这些名称，存档区也能按标签筛选。
- 存档草稿可以继续编辑名称、正文和标签，并同时显示标签颜色与分类名。
- 标签颜色按草稿创建时间在默认、5 天、7 天和 30 天四档降低饱和度；编辑草稿仍按最后编辑时间重新计算清理周期。
- 主界面划定提示更清楚；修复分类名称需要点击两次“保存名称”才显示已保存的问题，现在一次点击即可保存并退出编辑。

## 从 0.9.5 升级

在 0.9.5 中选择“草稿本 → 检查更新…”，应能发现 0.9.6。点击“下载并打开安装包”后，应用会校验 SHA-256 并打开 DMG。请退出旧版，再将新版“草稿本”拖入“应用程序”并选择替换；安装不会删除保存在本机的草稿。

当前仍是未经过 Apple Developer ID 签名和公证的公开测试版。首次打开步骤见[安装说明](https://github.com/hy198619/draftbook/blob/main/docs/INSTALL.md)。Release 同时提供 `SHA256SUMS.txt`，可供手动核对。

草稿保存在本机；只有主动检查或下载更新时才连接 GitHub，不会上传草稿内容。遇到问题请通过 [GitHub Issues](https://github.com/hy198619/draftbook/issues) 反馈，截图前请遮挡私人内容。
