# DraftBook（草稿本）0.9.7 Public Beta

给一人公司主理人和内容创作者的草稿本，一个文字的临时中转站。

[下载 DraftBook 0.9.7（macOS 通用版）](https://github.com/hy198619/draftbook/releases/download/v0.9.7/DraftBook-v0.9.7-macOS-unsigned.dmg)

系统要求：macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

## 本次更新

- 顶部工具栏默认自动收起。将鼠标移到窗口内部最上方并停留约 1 秒即可呼出；工具栏展开时会占用自己的布局空间，不会遮挡输入区或草稿。
- 窗口拖到屏幕左侧或右侧后可以自动收到屏幕外，仅保留约 8pt 宽的窄边；鼠标移入窄边即可呼出并继续输入。当前优先支持单显示器场景，也可以在“设置 → 通用 → 窗口”关闭该功能。
- 加强贴边呼出后的窗口激活与输入焦点处理，并修复松开鼠标后偶尔没有识别到贴边的问题。
- 输入区和空状态统一显示“写完一条，记得 ⌘+↵ 划定草稿”，让唯一需要记住的操作更明确。
- 修复 Markdown 引用后的普通段落仍被算入引用的问题；后续内容不再需要额外插入空行。

## 从 0.9.6 升级

在 0.9.6 中选择“草稿本 → 检查更新…”，应能发现 0.9.7。点击“下载并打开安装包”后，应用会校验 SHA-256 并打开 DMG。请退出旧版，再将新版“草稿本”拖入“应用程序”并选择替换；安装不会删除保存在本机的草稿。

当前仍是未经过 Apple Developer ID 签名和公证的公开测试版。首次打开步骤见[安装说明](https://github.com/hy198619/draftbook/blob/main/docs/INSTALL.md)。Release 同时提供 `SHA256SUMS.txt`，可供手动核对。

草稿保存在本机；只有主动检查或下载更新时才连接 GitHub，不会上传草稿内容。遇到问题请通过 [GitHub Issues](https://github.com/hy198619/draftbook/issues) 反馈，截图前请遮挡私人内容。
