DraftBook（草稿本）0.9.6 公开测试版
========================

感谢参与测试。

重要说明
--------

这个测试版本尚未使用 Apple Developer ID 签名，也没有经过 Apple 公证。
macOS 第一次打开时会阻止运行，这是系统对未验证开发者应用的正常保护措施。

请只从官方 GitHub 仓库的 Releases 页面下载，并核对同一 Release 提供的 SHA-256。

安装
----

1. 将“草稿本”拖入旁边的“Applications”文件夹。
2. 到“应用程序”文件夹双击“草稿本”。
3. 看到无法验证开发者的提示后，关闭提示。
4. 打开“系统设置 → 隐私与安全性”。
5. 向下滚动到“安全性”，点击“仍要打开”。
6. 再次确认“打开”。

完成一次后，今后可以正常双击打开。

隐私
----

草稿完全保存在本机，当前版本没有账号、统计分析或网络上传功能。
数据目前没有加密，请勿长期保存密码、私钥、恢复码等高度敏感信息。

反馈
----

请到项目 GitHub Issues 页面反馈。提交截图前请遮挡私人内容。
