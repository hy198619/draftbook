# 如何提供反馈

欢迎通过 GitHub Issues 提交反馈。为了提高处理效率，请尽量包含：

- macOS 版本和 Mac 芯片类型；
- 草稿本版本号；
- 你原本想完成什么；
- 实际发生了什么；
- 能稳定复现问题的操作步骤；
- 必要时附截图。

macOS 0.9.8 或更高版本可选择“帮助 → 导出诊断日志…”，将生成的文本文件一并附上。它会记录版本、系统、芯片和最近的窗口交互事件，不会记录草稿正文、搜索词、标签名称或剪贴板内容。发送前仍请自行打开检查。

请不要在 Issue 或截图中暴露真实草稿、手机号、账号、API Key、密码或其他私人信息。

功能建议除了说明“想要什么”，也请补充“你在什么场景下需要它”。这比单独罗列功能更有帮助。
