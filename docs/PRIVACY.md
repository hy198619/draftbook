# 隐私说明

草稿本是一款本地优先的 macOS 应用。

## 不会收集的内容

- 不要求注册账号；
- 不包含分析统计或广告 SDK；
- 不上传草稿正文；
- 不收集设备标识；
- 不自动发送崩溃日志；
- 不自动发送诊断日志；
- 不会在后台自动检查更新；只有用户主动点击“检查更新…”或下载新版时，才向 GitHub 请求公开的版本信息、校验文件和安装包，不会上传草稿正文。

## 本地数据

草稿及设置保存在用户自己的 Mac 上。草稿主数据和自动备份位于：

```text
~/Library/Application Support/com.yangyuxuan.DraftBook/
```

设置项由 macOS 的 UserDefaults 保存。

为排查窗口、焦点和工具栏异常，0.9.8 起会在上述应用数据目录的 `Diagnostics` 子目录保存最近两段运行事件，每段最多约 512 KB。事件只包含时间、应用和窗口状态，不记录草稿正文、搜索词、标签名称或剪贴板内容；日志不会自动上传。

## 数据安全边界

本地草稿和备份目前没有加密。不要把草稿本当作密码管理器，也不建议长期保存密码、私钥、恢复码或其他高度敏感信息。

## 用户主动导出

只有当用户主动选择导出时，App 才会将 TXT、Markdown、完整 JSON 备份或诊断报告写入用户选择的位置。诊断报告会额外列出草稿本版本、macOS 版本、芯片架构以及脱敏后的应用路径，发送前仍建议自行打开检查。
