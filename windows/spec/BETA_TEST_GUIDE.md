# DraftBook Windows 小范围内测指南

## 内测目标

首轮不是收集“好不好用”的泛化反馈，而是验证四个硬门槛：

1. 微软拼音、搜狗、微信输入法等中文 IME 不丢字、不拆分组合文本；
2. 快速连续输入、划定、编辑和退出后，重启能恢复最后内容；
3. Windows 10/11 的 x64 与 Windows 11 ARM64 都能安装、启动、卸载对应程序包；
4. 完整备份恢复、主文件损坏恢复和保存失败提示不会让情况变得更坏；
5. 安装版能发现正确架构的新版，下载、校验、重启安装并保留草稿。

## 测试人群最小组合

| 系统 | 架构 | 建议人数 | 必测输入法 |
|---|---:|---:|---|
| Windows 10 22H2 | x64 | 2 | 微软拼音 + 一种第三方输入法 |
| Windows 11 23H2/24H2/25H2 | x64 | 3 | 微软拼音、搜狗或微信输入法 |
| Windows 11 | ARM64 | 1–2 | 微软拼音 |

ARM64 测试者必须使用 `win-arm64` 包；x64 测试者使用 `win-x64` 包。

## 测试前

- 确认“关于文件”或包名标记为 `0.9.6-preview.5`，并记录测试架构；
- 核对 Setup.exe 文件名中的 `x64` / `arm64`，并校验对应 SHA-256；
- 双击 Setup.exe 安装；当前内测包未代码签名，SmartScreen 可能需要选择“更多信息 → 仍要运行”；
- 安装完成后确认草稿本自动启动，桌面和开始菜单均有快捷方式；
- 首轮只用指南里的合成文本，不输入密码、API Key、真实客户信息或隐私草稿；
- 记录 Windows 版本、系统架构、输入法名称及版本。

## 15 分钟必测脚本

1. 输入 `中文输入法组合态测试：西安、方案、人工智能。` 中途多次选词、翻页、回删，确认候选窗不消失。
2. 连续输入 30 秒，不停顿地按 `Ctrl+Enter`，确认候选词未上屏时不会误划定，上屏后才划定。
3. 划定三条草稿，立即编辑第一条，随后直接关闭窗口。重启后逐字核对。
4. 输入带普通换行、空行和连续空格的文本，划定后逐行核对；再输入标题、加粗、列表、引用、代码块和 `https://example.com`。
5. 分别测试直接网址、`[官网](https://example.com)` 和 `[https://example.com](https://example.com)`；普通单击应编辑，`Ctrl+单击` 应打开网页，重启后仍能正常进入软件。
6. 切换五种分类，点击颜色标签底部的“自定义分类名称…”，改名后用搜索和分类筛选核对。
7. 把草稿固定、存档、删除、恢复；在回收站用合成草稿验证永久删除确认。
8. 导出 TXT、Markdown 和完整 JSON；新增一条草稿后从 JSON 恢复，确认恢复前安全备份存在。
9. 将窗口收窄到最小宽度，开启置顶，与浏览器、微信或 Word 并排使用 10 分钟。
10. 准备长短不一的合成草稿，分别把鼠标停在草稿正文、卡片头部和空白区域滚动；确认滚动距离稳定，Markdown 正文区域不会突然停止响应。若有触控板，再与普通鼠标对比。
11. 在顶部连续输入至少 20 行合成文字，确认输入区随正文向下增高且没有内部滚动条；继续输入到内容超过窗口，确认整页能跟随光标滚动，下方草稿仍可访问。再编辑一条至少 20 行的已划定草稿，核对相同行为和草稿间距。

## 安装、更新与卸载专项

1. 分别从桌面和开始菜单快捷方式启动，都应打开同一个草稿本窗口；重复双击不应产生第二个进程。
2. 打开“更多 → 检查更新…”。已是最新版时应明确提示当前版本，断网时不应影响草稿编辑与本地保存。
3. 有后续内测版时，确认只下载与本机架构相符的通道；更新下载后选择立即重启，核对版本号、快捷方式、窗口设置和合成草稿。
4. 再次测试“更新已就绪”时选择暂不重启，退出后重新打开，应先完成安装再进入主窗口。
5. 在设置中关闭“自动检查并下载更新”，重启后仍可手动检查。
6. 从 Windows“已安装的应用”卸载草稿本，快捷方式和程序文件应删除；`%LOCALAPPDATA%\DraftBook\` 中的用户数据默认保留。

`0.9.6-preview.2` 是首个接入新更新链路的版本；本次请重点验证从 `preview.4` 自动升级到 `preview.5` 的完整流程。

## 窗口与界面专项

1. 首次启动应保持非置顶状态，并在右上角图钉旁显示一次箭头提示；关闭重启后提示不应再次出现。
2. 分别在 100%、125%、150%、200% 缩放下启动，标题栏和窗口底部都必须留在任务栏工作区内。
3. 把窗口拖到不同缩放的第二台显示器，关闭后拔掉该显示器再启动，窗口必须回到仍存在的屏幕。
4. 最大化后退出再启动；恢复正常窗口后，尺寸和位置应合理，不能出现接近整屏的异常窄长窗口。
5. 使用“更多 → 恢复默认窗口大小和位置”，窗口应回到当前屏幕中央附近的窄栏尺寸。
6. 检查标题栏、任务栏、EXE 和桌面快捷方式均显示草稿本图标，而不是系统默认白框图标。
7. 在 Windows 浅色、深色和高对比模式下检查正文、次要文字、分隔线、焦点和菜单可读性。

## 反馈必填字段

- 安装包：`win-x64` / `win-arm64`；
- Windows 版本与 OS build；
- 设备 CPU；
- 输入法及版本；
- 复现步骤、预期结果、实际结果；
- 问题发生后重启是否恢复；
- 只提供合成测试文本的截图或备份，不上传真实草稿。

- P0：丢字、覆盖数据、无法启动、恢复导致数据不可用。
- P1：中文候选窗异常、划定错位、主要流程不可用。
- P2：布局、预览、操作反馈等不阻断问题。
