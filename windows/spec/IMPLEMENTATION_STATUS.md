# Windows 内测实现状态

> 基线：macOS `a728753` / `v0.9.6`
>
> 检查日期：2026-10-20
>
> Windows 源码版本：`0.9.6-preview.3`；macOS 仍为 `0.9.6`

## 已完成代码

- .NET 10 + WPF 单窗口，默认 420 × 680 DIP，支持置顶和窗口尺寸、位置、最大化状态记忆；
- 首次启动默认不置顶，通过图钉旁的一次性箭头提示说明置顶功能；
- PerMonitorV2 DPI 声明、按当前显示器工作区限制窗口、旧版超大窗口尺寸迁移和“恢复默认窗口大小和位置”；
- WPF Fluent 系统主题、正式多尺寸 Windows 图标、窄栏顶部工具栏、按需搜索和轻量草稿列表；
- 顶部输入区、`Ctrl+Enter` 划定、IME 组合态拦截、草稿原文编辑；
- schema v5 数据模型，与 macOS 完整 JSON 字段和枚举字符串兼容；
- 280 ms 防抖自动保存、串行写入、退出前 flush、保存失败可见提示；
- 同目录临时文件替换、上一版副本、每日备份、保留数裁剪和损坏恢复；
- 遇到更高 schema 主文件时停止启动，不回退、不覆盖；
- 分类、分类名自定义、颜色衰减、搜索和组合筛选；
- 清理台、延后、固定、存档、回收站、恢复和永久删除；
- Markdig CommonMark/GFM 解析与 WPF 原生预览，不执行 HTML，不加载远程图片；
- 普通回车按原换行呈现；单条预览异常时降级显示原文，不影响其他草稿或下次启动；
- `Ctrl+单击` 打开 HTTP/HTTPS、Markdown 中的已存在本地文件以及未标记的 Windows 绝对路径；可执行类型二次确认；
- 剪贴板占用重试，复制保留 Markdown 原文；
- TXT、Markdown、完整 JSON 导出与完整备份恢复；
- 单实例互斥，防止同一用户会话中两个进程并发写入；
- 重复启动时恢复并置前已有主窗口，避免双击快捷方式后看起来“没有打开”；
- `win-x64` 和 `win-arm64` 自包含 Setup.exe、桌面/开始菜单快捷方式、SHA-256 和 GitHub Actions Windows 构建矩阵；
- Velopack `win-x64-beta` / `win-arm64-beta` 独立更新通道，支持 GitHub Release 检查、下载、校验、重启安装和失败时保留旧版；
- 默认最多每 12 小时自动检查一次，可关闭自动检查，并保留手动检查入口；更新前强制 flush 草稿。

## 与 macOS 0.9.6 尚有差异

- 尚无删除后的即时“撤销”提示，但可在回收站恢复；
- 存档时不弹出单独标题/分类对话框，而是使用建议标题，存档后仍可编辑标题和分类；
- 尚无代码签名；Setup.exe 和卸载入口已生成，但尚未在 Windows 真机验证；
- `0.9.6-preview.3` 延续首轮截图后的视觉重构，但尚未根据 Windows 真机渲染做第二轮校准。

这些差异不阻塞首轮小范围内测，但必须在扩大测试或公开发布前重新评估。
