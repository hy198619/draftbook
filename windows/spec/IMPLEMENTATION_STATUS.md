# Windows 内测实现状态

> 基线：macOS `a728753` / `v0.9.6`
>
> 检查日期：2026-10-12

## 已完成代码

- .NET 10 + WPF 单窗口，最小宽度 360 px，支持置顶和窗口尺寸记忆；
- 顶部输入区、`Ctrl+Enter` 划定、IME 组合态拦截、草稿原文编辑；
- schema v5 数据模型，与 macOS 完整 JSON 字段和枚举字符串兼容；
- 280 ms 防抖自动保存、串行写入、退出前 flush、保存失败可见提示；
- 同目录临时文件替换、上一版副本、每日备份、保留数裁剪和损坏恢复；
- 遇到更高 schema 主文件时停止启动，不回退、不覆盖；
- 分类、分类名自定义、颜色衰减、搜索和组合筛选；
- 清理台、延后、固定、存档、回收站、恢复和永久删除；
- Markdig CommonMark/GFM 解析与 WPF 原生预览，不执行 HTML，不加载远程图片；
- `Ctrl+单击` 打开 HTTP/HTTPS、Markdown 中的已存在本地文件以及未标记的 Windows 绝对路径；可执行类型二次确认；
- 剪贴板占用重试，复制保留 Markdown 原文；
- TXT、Markdown、完整 JSON 导出与完整备份恢复；
- 单实例互斥，防止同一用户会话中两个进程并发写入；
- `win-x64` 和 `win-arm64` 自包含发布、ZIP、SHA-256 和 GitHub Actions Windows 构建矩阵。

## 已完成的非 Windows 验证

- 核心测试：49/49 通过；
- 核心行覆盖率：91.56%，分支覆盖率 74.28%；
- 整体 Release 交叉编译：0 警告、0 错误；
- x64 产物文件头：PE32+ GUI x86-64；
- ARM64 产物文件头：PE32+ GUI AArch64；
- 两个 ZIP 结构完整性和 SHA-256 校验通过；
- 应用项目与测试项目未发现 NuGet 已知漏洞。

## 尚未在 Windows 验证

- 微软拼音、搜狗、微信输入法的候选窗、翻页、回删和快捷键交互；
- Windows 10 22H2 与 Windows 11 的真实启动、窄窗口布局、高 DPI、多显示器和置顶；
- x64 与 ARM64 的冷启动时间、空闲内存和长时间输入稳定性；
- 真实默认浏览器、文件关联、剪贴板争用和 SmartScreen 表现；
- 断电、强制杀进程、磁盘满、无权限目录等真实故障注入；
- Windows CI 工作流尚未推送到 GitHub 运行。

## 与 macOS 0.9.6 尚有差异

- 尚无手动更新检查、下载和校验流程；
- 尚无删除后的即时“撤销”提示，但可在回收站恢复；
- 存档时不弹出单独标题/分类对话框，而是使用建议标题，存档后仍可编辑标题和分类；
- 尚无代码签名、MSIX/MSI 安装包和卸载入口，首轮为便携 ZIP；
- 视觉层只完成功能性还原，尚未根据 Windows 真机截图做精细视觉校准。

这些差异不阻塞首轮小范围内测，但必须在扩大测试或公开发布前重新评估。
