# Windows 第一阶段验收清单

> 所有测试使用合成文字，不使用真实草稿。

## 自动化测试

- schema v5 合成快照可读取、规范化写回，并保持所有业务字段；
- schema 1/2 缺省字段迁移；schema 6/999 拒绝且主数据不变；
- 空白顶部输入不划定；非空输入划定后输入区清空；
- 固定优先、创建时间倒序；编辑旧草稿不改变创建顺序；
- 输入区和草稿编辑在防抖时间后落盘；显式 flush 立即落盘；
- 模拟主文件损坏后从最近有效备份恢复；
- 中途失败不会留下半截 `drafts.json`；两个实例不能并发写；
- 复制得到原始 Markdown 文本；
- 保存失败时保留编辑器内容并显示可操作错误，不用旧快照覆盖输入。

## 中文 IME 真机测试

至少覆盖微软拼音和一款常用第三方输入法（优先搜狗拼音）：

1. 连续输入 200 字，反复翻页选候选、撤销、移动光标和插入文字；
2. 候选未确认时等待多次自动保存，不得关闭候选、吞字或跳光标；
3. 候选未确认时按 `Ctrl+Enter`，不得划定草稿；确认后再按才划定；
4. 中英文、全半角标点、Emoji、生僻字、换行和粘贴混合输入；
5. 编辑既有长草稿时重复上述操作；
6. 窗口失焦、重新聚焦、切换输入法后继续输入；
7. 自动保存期间快速连续输入，最终落盘内容必须与控件内容逐字一致。

通过标准：每个输入法至少连续 15 分钟零吞字、零旧文本回写、零异常划定。

## 数据可靠性

- 输入后等待一个防抖周期，强制结束进程，重启后恢复；
- 输入后立即正常关闭，重启后恢复；
- 划定、编辑、复制分别重启复核；
- 只读目录、磁盘空间不足或文件占用时显示错误，内存中的文字不丢；
- 连续重启 20 次，快照始终可解析；
- Windows 数据目录与任何 macOS 目录完全隔离。

## 布局、窗口与性能

- 360 DIP 最小宽度下输入、操作和正文不横向溢出；
- 1366×768、150% 缩放下首次启动，标题栏和窗口底部均在工作区内；
- 100%、125%、150%、200% 缩放之间切换，窗口内容不裁切，字体和图标不模糊；
- 双显示器混合 DPI 下保存位置；移除原显示器后重启，窗口自动回到可用屏幕；
- 首次置顶提示只显示一次，图钉可立即切换置顶状态并持久化；
- 1、100、1000 条合成草稿下滚动和编辑无明显卡顿；
- 单条 50,000 字中文长文本完整展开、可编辑、可复制；
- 100 条普通草稿、空闲 10 分钟后记录工作集内存；首阶段目标不高于 150 MB；
- 冷启动到可输入记录 20 次中位数；目标不高于 1.5 秒；
- 后台空闲时无持续高 CPU、无联网请求。

资源目标是待验证门槛，不是当前已达到的结果；若真机数据不达标，再依据 profiler 结果调整。

## 系统行为

- “保持最前”开关即时生效并持久化；
- 普通 Enter 换行，`Ctrl+Enter` 划定，快捷键提示与实际一致；
- 剪贴板只写用户主动复制的正文；
- 应用不请求账号、不上传文本；默认最多每 12 小时向 GitHub 检查一次公开版本信息，可在设置中关闭；
- Setup.exe 按当前用户安装，创建桌面和开始菜单快捷方式；卸载删除程序和快捷方式，保留 `%LOCALAPPDATA%\DraftBook\` 用户数据；
- x64 与 ARM64 使用独立更新通道，更新包必须通过 feed 中的 SHA-256 校验；重启更新前必须先刷新草稿保存。

## 暂不验收

标签、Markdown 预览、搜索、清理台、存档、回收站、完整备份导入、自动备份、链接打开、安装与更新已超出第一阶段最小闭环并进入当前内测范围。自动更新、中文 IME、真实安装卸载仍必须通过 Windows 真机验收；代码签名尚未完成。
